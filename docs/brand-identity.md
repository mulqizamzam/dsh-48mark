# Brand identity

The 48mark mark expresses a layout system moving toward a verified finish: three outlined modules suggest composable interface regions, while the final check completes the grid. It represents design implementation plus quality validation rather than a generic model or chat symbol.

- **Primary palette:** deep teal `#102A2A`, warm off-white `#F3F6ED`, and acid green `#C7F36B`.
- **Light and dark variants:** `assets/logo-light.svg` and `assets/logo-dark.svg` share identical geometry and differ only in contrast choices for the wordmark and mark surfaces.
- **Compact icon:** `assets/icon.svg` uses the same modular grid at a square 128×128 viewBox; no remote images, fonts, scripts, or raster dependencies are required.
- **Small-size behavior:** three cells and the check remain simple strokes and solid surfaces. The wordmark is omitted from the compact icon.
